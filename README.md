# 🏆 The Richards World Cup 2026 Predictor

A fun and interactive Streamlit application that predicts the outcomes of the FIFA World Cup 2026!

## Features

- **Team Selection**: Choose your favorite teams to predict
- **Multiple Prediction Methods**:
  - Random Predictor: Generate unpredictable predictions
  - Favorites: Predictions based on your selected teams
  - Statistical Model: Data-driven predictions based on historical performance
- **Tournament Overview**: See key tournament information
- **Teams by Region**: Browse all 48 qualified teams organized by region
- **Interactive UI**: Clean, user-friendly interface with real-time predictions

## Regions Included

- **CONCACAF**: Canada, Mexico, USA, Costa Rica, Panama, Jamaica
- **South America**: Argentina, Brazil, Chile, Colombia, Ecuador, Paraguay, Peru, Uruguay
- **Europe**: England, France, Germany, Italy, Netherlands, Poland, Spain, Portugal, Belgium, Croatia
- **Africa**: Egypt, Cameroon, Morocco, Nigeria, Senegal, South Africa, Algeria
- **Asia**: Japan, South Korea, Australia, Iran, Saudi Arabia, Qatar, Uzbekistan

## Installation

Clone the repository and install dependencies:

```bash
pip install -r requirements.txt
```

## Running the App

```bash
streamlit run streamlit_app.py
```

Then open your browser to the local Streamlit URL (typically `http://localhost:8501`).
